# Plan de Investigación: APIs de Generación de Videos

## Objetivo
Investigar en profundidad las siguientes APIs de generación de videos: RunwayML Gen-2, Pika Labs API, Luma AI Dream Machine, Stable Video Diffusion, y Leonardo.ai.

## Aspectos a Analizar por Herramienta
Para cada API se debe investigar:
1. Capacidades de generación (texto a video, imagen a video)
2. Duración máxima de videos
3. Resoluciones disponibles
4. APIs y documentación técnica
5. Precios y limitaciones
6. Formatos optimizados para diferentes redes sociales (TikTok, Instagram, YouTube)
